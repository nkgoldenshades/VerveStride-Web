## Subscription Upsell Math

### Pro Subscription ($4.99/month)
- Includes: 100 credits/month
- Cost to you: ~$20 (100 credits = 50 images @ $0.03 API cost)
- **Your profit:** $4.99 - $20 = **-$15.01** ❌ LOSS

**Solution:** Don't include unlimited credits in Pro. Make it:
- **Free:** Unlimited chat, 10 free credits/month
- **Pro ($4.99/mo):** 50 credits/month + priority support
- **Elite ($9.99/mo):** 200 credits/month + priority support

### Revised Pro Subscription
- Includes: 50 credits/month = ~25 images
- Cost to you: ~$1.50 (50 credits @ $0.03 API cost)
- **Your profit:** $4.99 - $1.50 = **$3.49** ✅ PROFIT

## Profit Levers You Control

### 1. **Volume**: More users = more profit
- 100 users → $70/month
- 1,000 users → $700/month
- 10,000 users → $7,000/month

### 2. **Subscription Adoption**: Higher % on paid tiers
- If 20% of users buy Pro: +$3.49 × 200 = +$698/month
- If 5% buy Elite: +$7.49 × 50 = +$375/month

### 3. **Feature Usage**: Encourage higher generation
- Daily push: "Generate your workout plan" = +1 audio per user
- Weekly: "Meal plan ready" = +1 video per user
- Results: +5 video generations/user/month = +$75/month (100 users)

### 4. **Price Adjustments**: Gradual increases
- After 6 months: Increase video from $1.50 → $2.00 (still beats Runway's $2.50)
- User impact: "Small optimization"
- Profit impact: +$100/month per 100 users
