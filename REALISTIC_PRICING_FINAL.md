## The Math

**Per User Economics:**

**Free User:**
- 50 messages/day × $0.00013 = $0.0065/day
- 3 meal analyses/day × $0.00018 = $0.00054/day
- **Monthly cost to you: ~$0.20**
- **Acceptable** if 10% convert to Pro

**Pro User ($4.99/mo):**
- Costs you maybe $0.50-1.00 in API calls
- **Profit: $4.00-4.50/mo per user**
- If 1000 Pro users = $4,000-4,500/mo profit

**Elite User ($9.99/mo):**
- Even heavy use costs maybe $3-5 in API
- **Profit: $5-7/mo per user**
- If 500 Elite users = $2,500-3,500/mo profit
