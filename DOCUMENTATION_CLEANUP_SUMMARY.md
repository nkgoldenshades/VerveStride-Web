## 📝 Maintenance Guidelines

### Keep:
- ✅ User-facing documentation (README, guides)
- ✅ Setup/deployment instructions
- ✅ Architecture/design documents
- ✅ Legal/compliance templates
- ✅ Marketing/business strategy

### Remove:
- ❌ Temporary fix logs
- ❌ Session summaries
- ❌ "FIXED" or "COMPLETE" status files
- ❌ Duplicate guides
- ❌ Outdated troubleshooting docs

### When to Create New MD Files:
- ✅ Major new feature documentation
- ✅ Important architectural changes
- ✅ User-facing guides
- ❌ Temporary fixes (use git commits instead)
- ❌ Session notes (use project management tools)
